# Temporary web test records

Local development database only. Created 20 November 2026.

The hardcoded fixture set is in `backend/scripts/web-test-data.cjs`. It saves 75 initial linked records, labelled `DEMO-WEB-20261120`, to the local database. The current local set has 76 tracked records, including one alert generated by local tracking maintenance during verification. Existing records and permissions are not replaced. Nothing is deployed or seeded on the live website.

These are explicitly synthetic database snapshots for browsing and training. No false receipt, movement or trip-event ledgers are manufactured. Photos and documents are not faked; upload your own test files if required. Operational actions can require additional real workflow checks. Other accounts still follow their normal organization and depot scope.

## Re-run without duplicates

From `backend`:

```powershell
node scripts/web-test-data.cjs seed
```

The manifest at `outputs/web-test-data/manifest.json` tracks exact record IDs and original snapshots. Keep this file until the samples are removed. Re-running checks the existing set and does not reset edited records.

## Remove later

First run a rollback-only cleanup rehearsal:

```powershell
node scripts/web-test-data.cjs check
```

Then, when you want the samples removed:

```powershell
node scripts/web-test-data.cjs --remove
```

Both commands refuse non-local databases and production mode. Cleanup only targets the tracked set. It checks for edits and performs deletion in one transaction; the check command rolls that transaction back. If a sample has changed or dependent work prevents deletion, it stops without a partial cleanup. Do not bypass ledger protections or remove unrelated records. Review later work first. Actual removal renames the manifest to `manifest.json.removed`.

Immutable history created by using real workflow actions needs separate review; this script does not disable database protections to erase it.
